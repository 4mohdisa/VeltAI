# Security policy

## Reporting a vulnerability

Email **lumofit@gmail.com**. Please do not open a public issue for security
reports.

Include what you can:

- What the vulnerability is and where (endpoint, file, or screen)
- Steps to reproduce
- Impact as you understand it
- Any suggested fix

You'll get a reply acknowledging the report. Please allow reasonable time to
investigate and ship a fix before disclosing publicly.

## No bounty program

There is no bug bounty. We can't pay for reports, but we will credit you if
you'd like, and we're genuinely grateful — thank you for taking the time.
