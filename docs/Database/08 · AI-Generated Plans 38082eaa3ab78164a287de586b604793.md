# 08 · AI-Generated Plans

AI-generated daily targets, meal plans, and gym schedules. These are derived from onboarding + ongoing adherence data.

---

## `ai_daily_targets`

One row per (user, date). Generated nightly by cron for the next day.

```sql
CREATE TABLE ai_daily_targets (
  id                  UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  user_id             UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  target_date         DATE NOT NULL,

  -- Macros
  calorie_target      INT NOT NULL,
  protein_target_g    NUMERIC(5,1) NOT NULL,
  carbs_target_g      NUMERIC(5,1) NOT NULL,
  fat_target_g        NUMERIC(5,1) NOT NULL,
  fibre_target_g      NUMERIC(5,1),
  water_target_ml     INT,

  -- Activity targets
  expected_calories_burned INT,
  is_gym_day              BOOLEAN NOT NULL DEFAULT FALSE,
  recommended_gym_time    TIME,

  -- Sleep target for this night
  recommended_bedtime     TIME,

  -- Reasoning (for AI transparency)
  generation_reason       TEXT,
  generated_from_context  JSONB,   -- snapshot of inputs used
  model_version           TEXT DEFAULT 'gemini-3.5-flash',

  generated_at            TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  created_at              TIMESTAMPTZ NOT NULL DEFAULT NOW(),

  CONSTRAINT uq_daily_target UNIQUE (user_id, target_date)
);

CREATE INDEX idx_daily_targets_user_date ON ai_daily_targets(user_id, target_date DESC);

ALTER TABLE ai_daily_targets ENABLE ROW LEVEL SECURITY;
CREATE POLICY "daily_targets_own" ON ai_daily_targets
  USING (user_id = (SELECT id FROM users WHERE clerk_id = auth.uid()::TEXT));
```

## `ai_meal_plans`

Weekly meal plan generated by AI. Maps to user_meal_schedule slots.

```sql
CREATE TABLE ai_meal_plans (
  id                  UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  user_id             UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  week_start_date     DATE NOT NULL,        -- always a Monday

  plan_data           JSONB NOT NULL,       -- full meal plan structure
  /* Example plan_data:
  {
    "monday": {
      "breakfast": {
        "time": "07:00",
        "target_kcal": 500,
        "suggestions": ["oats with berries", "eggs and paratha", "protein smoothie"]
      },
      ...
    },
    ...
  }
  */

  total_planned_kcal_per_day  INT,
  generation_reason           TEXT,
  model_version               TEXT DEFAULT 'gemini-3.5-flash',
  generated_at                TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  created_at                  TIMESTAMPTZ NOT NULL DEFAULT NOW(),

  CONSTRAINT uq_meal_plan_week UNIQUE (user_id, week_start_date)
);

CREATE INDEX idx_meal_plans_user_week ON ai_meal_plans(user_id, week_start_date DESC);

ALTER TABLE ai_meal_plans ENABLE ROW LEVEL SECURITY;
CREATE POLICY "meal_plans_own" ON ai_meal_plans
  USING (user_id = (SELECT id FROM users WHERE clerk_id = auth.uid()::TEXT));
```

## `ai_gym_schedules`

Weekly gym schedule generated by AI.

```sql
CREATE TABLE ai_gym_schedules (
  id                  UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  user_id             UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  week_start_date     DATE NOT NULL,

  scheduled_days      JSONB NOT NULL,
  /* Example:
  {
    "monday":    {"scheduled": true,  "time": "18:00", "focus": "upper body"},
    "tuesday":   {"scheduled": false},
    "wednesday": {"scheduled": true,  "time": "18:00", "focus": "lower body"},
    ...
  }
  */

  total_sessions_planned  INT NOT NULL,
  generation_reason       TEXT,
  model_version           TEXT DEFAULT 'gemini-3.5-flash',
  generated_at            TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  created_at              TIMESTAMPTZ NOT NULL DEFAULT NOW(),

  CONSTRAINT uq_gym_schedule_week UNIQUE (user_id, week_start_date)
);

CREATE INDEX idx_gym_schedules_user_week ON ai_gym_schedules(user_id, week_start_date DESC);

ALTER TABLE ai_gym_schedules ENABLE ROW LEVEL SECURITY;
CREATE POLICY "gym_schedules_own" ON ai_gym_schedules
  USING (user_id = (SELECT id FROM users WHERE clerk_id = auth.uid()::TEXT));
```

## Plan generation cadence

| Plan type | Cadence | Trigger |
| --- | --- | --- |
| Daily targets | Nightly cron (23:00 local) | For next day, based on this week's adherence |
| Meal plan | Weekly (Sunday 22:00 local) | For next week, regenerates based on last week |
| Gym schedule | Weekly (Sunday 22:00 local) | For next week, regenerates based on missed days |

All generation is async — the user sees the new plan when they open the app on Monday morning.
