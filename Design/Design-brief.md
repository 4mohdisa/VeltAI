# Design

Everything visual: screen inventory, design philosophy, and the concrete tokens that ship in code.

## What's in here

| Page | Use it for |
| --- | --- |
| App Screens | Complete inventory of every screen in the iOS app, with brief layout descriptions. Look here when planning what to build next. |
| UI & Design System | Design philosophy, component library structure, helper function organisation. The "how we think about UI" reference. |
| Theme & Design Tokens | Concrete code-ready values for color, type, spacing, radius, shadow, animation. Lives at `/lib/design/tokens.ts` in the codebase. |

Start with App Screens to know what to build, then Theme & Design Tokens for the values to use, then UI & Design System for the patterns.
