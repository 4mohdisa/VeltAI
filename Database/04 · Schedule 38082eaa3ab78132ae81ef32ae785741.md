# 04 · Schedule

Daily routine and meal slot configuration. The AI uses this to recommend gym times, meal times, and lockout enforcement windows.

---

## `user_schedule` — daily routine

1:1 with users. Stores wake, work, gym, sleep windows.

```sql
CREATE TABLE user_schedule (
  id                          UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  user_id                     UUID NOT NULL UNIQUE REFERENCES users(id) ON DELETE CASCADE,

  -- Sleep
  wake_time                   TIME NOT NULL DEFAULT '07:00',
  bedtime                     TIME NOT NULL DEFAULT '23:00',
  target_sleep_hours          NUMERIC(3,1) DEFAULT 8.0,
  current_avg_sleep_hours     NUMERIC(3,1),
  sleep_issues                TEXT[] DEFAULT '{}', -- trouble_falling_asleep | wakes_at_night | wakes_early

  -- Work
  work_start_time             TIME,
  work_end_time               TIME,
  work_type                   TEXT,           -- sedentary | active | shift_work | remote | mixed
  works_weekends              BOOLEAN DEFAULT FALSE,

  -- Gym preferences (derived to user_gym_profile but echoed here for schedule view)
  preferred_gym_time          TIME,
  preferred_gym_days          TEXT[] DEFAULT '{}', -- mon, tue, wed, thu, fri, sat, sun

  created_at                  TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  updated_at                  TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

ALTER TABLE user_schedule ENABLE ROW LEVEL SECURITY;
CREATE POLICY "schedule_own" ON user_schedule
  USING (user_id = (SELECT id FROM users WHERE clerk_id = auth.uid()::TEXT));
```

## `user_meal_schedule` — meal slots with target macros

One row per meal slot. Generated by AI from onboarding, regenerates weekly.

```sql
CREATE TABLE user_meal_schedule (
  id                  UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  user_id             UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,

  meal_slot           TEXT NOT NULL,       -- breakfast | lunch | dinner | snack_morning | snack_afternoon | snack_evening | pre_workout | post_workout
  target_time         TIME NOT NULL,
  target_calories     INT NOT NULL,
  target_protein_g    NUMERIC(5,1) NOT NULL,
  target_carbs_g      NUMERIC(5,1) NOT NULL,
  target_fat_g        NUMERIC(5,1) NOT NULL,

  suggested_foods     TEXT[] DEFAULT '{}',  -- AI-suggested foods for this slot
  notes               TEXT,

  is_active           BOOLEAN NOT NULL DEFAULT TRUE,
  generated_by_ai     BOOLEAN NOT NULL DEFAULT TRUE,
  ai_generated_at     TIMESTAMPTZ,

  created_at          TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  updated_at          TIMESTAMPTZ NOT NULL DEFAULT NOW(),

  CONSTRAINT uq_meal_slot UNIQUE (user_id, meal_slot)
);

CREATE INDEX idx_meal_schedule_user ON user_meal_schedule(user_id) WHERE is_active = TRUE;

ALTER TABLE user_meal_schedule ENABLE ROW LEVEL SECURITY;
CREATE POLICY "meal_schedule_own" ON user_meal_schedule
  USING (user_id = (SELECT id FROM users WHERE clerk_id = auth.uid()::TEXT));
```
