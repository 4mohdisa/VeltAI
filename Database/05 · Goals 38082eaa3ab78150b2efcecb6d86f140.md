# 05 · Goals

Multi-goal support. A user might want to lose 5kg AND go to gym 4x/week AND sleep 8 hours — these are tracked separately with their own targets and progress.

---

## `user_goals`

```sql
CREATE TABLE user_goals (
  id                  UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  user_id             UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,

  goal_type           TEXT NOT NULL,
    -- weight_loss           lose X kg
    -- weight_gain           gain X kg
    -- muscle_gain           gain X kg lean mass
    -- gym_frequency         go to gym X times/week
    -- gym_consistency       maintain X-day streak
    -- calorie_target        hit X kcal/day on Y% of days
    -- protein_target        hit X g protein/day
    -- sleep_hours           average X hours/night
    -- water_intake          drink X litres/day
    -- general_health        broad goal, no specific metric

  is_primary          BOOLEAN NOT NULL DEFAULT FALSE, -- the user's stated main goal

  target_value        NUMERIC(10,2),                   -- the number to hit
  target_unit         TEXT,                            -- kg | times_per_week | days | kcal | g | hours | litres
  starting_value      NUMERIC(10,2),                   -- their value when goal was set
  current_value       NUMERIC(10,2),                   -- updated by cron / events

  target_date         DATE,                            -- when they want to achieve it
  why_text            TEXT,                            -- the user's stated reason

  status              TEXT NOT NULL DEFAULT 'active',
    -- active | achieved | paused | abandoned | expired
  achieved_at         TIMESTAMPTZ,
  paused_at           TIMESTAMPTZ,

  created_at          TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  updated_at          TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  deleted_at          TIMESTAMPTZ                      -- soft delete
);

CREATE INDEX idx_goals_user_active ON user_goals(user_id) WHERE status = 'active' AND deleted_at IS NULL;
CREATE INDEX idx_goals_user_primary ON user_goals(user_id) WHERE is_primary = TRUE;

ALTER TABLE user_goals ENABLE ROW LEVEL SECURITY;
CREATE POLICY "goals_own" ON user_goals
  USING (user_id = (SELECT id FROM users WHERE clerk_id = auth.uid()::TEXT));
```

## Goal examples

### Weight loss goal

```json
{
  "goal_type": "weight_loss",
  "is_primary": true,
  "target_value": 75.0,
  "target_unit": "kg",
  "starting_value": 82.5,
  "current_value": 81.0,
  "target_date": "2026-12-31",
  "why_text": "My brother's wedding in December, want to look good in the photos"
}
```

### Gym frequency goal

```json
{
  "goal_type": "gym_frequency",
  "target_value": 4,
  "target_unit": "times_per_week",
  "starting_value": 1,
  "current_value": 2,
  "why_text": "I'm sick of feeling tired all the time"
}
```

### Sleep goal

```json
{
  "goal_type": "sleep_hours",
  "target_value": 8.0,
  "target_unit": "hours",
  "current_value": 6.5
}
```

## How goals drive the app

- **AI plan generation** reads `is_primary = true` goal first, plus all other active goals
- **Daily calorie target** is calculated from the weight goal (deficit/surplus based on `target_date`)
- **Lockout enforcement** is influenced by the gym frequency goal
- **Nudge generation** picks goals showing slowest progress for encouragement
- **Rank-up celebrations** mention how the rank gets them closer to their goal
